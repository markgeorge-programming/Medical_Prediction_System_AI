# Project Datasets Guide

## 1. ECG Project (MIT-BIH Arrhythmia Database)
- **Status:** External download required (too large for GitHub).
- **Source:** [PhysioNet MIT-BIH Database](https://physionet.org/content/mitdb/)
- **Setup Instructions:** Download the raw files and place them into a local `data/ecg/` directory before running `ECG_Project.ipynb`.

## 2. Chronic Kidney Disease (CKD) Dataset
- **Status:** Included in repository (`chronic_kidney_disease_clean.arff`).
- **Description:** Pre-processed ARFF format used directly by the CKD model notebook.

## 3. Heart Failure Clinical Records
- **Status:** Included in repository (`heart_failure_clinical_records_dataset.csv`).
- **Description:** Tabular clinical data loaded locally by `ProjectHeartFailure.ipynb`.
